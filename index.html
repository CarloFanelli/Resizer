Drag a line. Reload the page. The widths are still there.

Resizer puts a draggable handle between sibling elements, saves their widths in localStorage and shares out the space again when one of them is hidden. Written in TypeScript, with no dependencies.

Resizer listens for mouse events, so the handles do not respond to touch yet. Open this page on a computer to try it.

What Resizer saved

After every drag the widths are written, as percentages of the row, to localStorage["resizableElementsSize"].

The code behind this page

        
Every panel needs an id. The handles are created for you.


import Resize from './bin/Resize.js';

const panels = document.querySelectorAll('.resizableElement');

new Resize({
  resizableElements: [...panels],
  resizerClassList: 'resizer',    // classes for each handle
  saveName: 'resizableElements',  // localStorage key prefix
  classToCheck: 'hidden'          // class that hides a panel
});
